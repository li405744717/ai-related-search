## 商业模式创新趋势

| 趋势 | 说明 |
|------|------|
| 分层订阅精细化 | OpenAI 6 档定价（Free/Go/Plus/Pro/Pro+/Enterprise） |
| Agent 成为新收入引擎 | Claude Code 25 亿、Codex 500 万周活、Perplexity Computer |
| 使用量计费叠加 | 订阅基础上加 usage-based，API 持续涨价 |
| 多模型平台化 | Bedrock/OpenRouter 统一接口，企业从"选一家"变为"多模型路由" |
| AI 公司估值逼近万亿 | Anthropic 9650 亿、OpenAI 8520 亿 |
| 代码 Agent 爆发 | Cursor 一年从 2→20 亿 ARR，Claude Code 25 亿 |

## 关键洞察

1. **双巨头竞赛** — Anthropic（9650 亿）vs OpenAI（8520 亿），均未盈利但融资规模创纪录
2. **收入增长验证** — OpenAI 年化 200 亿+、Anthropic ~140 亿，但 OpenAI 预计 2026 亏 140 亿
3. **Agent 驱动第二曲线** — Codex/Claude Code/Perplexity Computer 成为增长引擎
4. **平台 vs 工具** — Codex 从 coding 工具→全能工作平台，ChatGPT 切入求职/简历
5. **多云分发成为默认** — OpenAI on Bedrock 意味着模型不再是壁垒，分发/合规才是
6. **中国 AI 公司资本化** — 智谱 7000 亿港元、A+H 双上市开创先例
