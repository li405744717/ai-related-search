协议标准化

MCP（Model Context Protocol）

定位："AI 的 USB-C"。Agent↔工具连接标准。2月推进 Streamable HTTP + OAuth 2.1。但安全堪忧：60天 30+ CVE。

A2A（Agent-to-Agent）

Google 提出，Linux Foundation 托管。4月超 150 个组织加入。CrewAI/LangGraph/ADK 均已适配。

架构演进趋势

MoE 稀疏率竞争

NVIDIA 选择 10% 激活率（550B 总参/55B 活跃），DeepSeek 约 3%（1.6T/49B）。更低激活=更高推理效率但训练更难。

混合架构创新

NVIDIA Nemotron 引入 Mamba(SSM)+Transformer 混合 MoE，兼具 SSM 的线性复杂度推理和 Transformer 的表达力。

核心洞察：中国模型集中爆发（2月 HuggingFace 前10均为中国模型）。模型设计从"对话"全面转向"长时 Agent 任务"。Meta 意外转向闭源（Muse Spark），Apache 2.0/MIT 成为开源主流许可。

商业模式演变

分层订阅精细化

OpenAI 扩展至6档：Free → Go($8) → Plus($20) → Pro($100) → Pro+($200) → Enterprise。低端抢用户，高端提ARPU。

Agent 驱动第二曲线

Codex/Claude Code/Perplexity Computer 成为增长引擎。对话式AI增长放缓，自主执行类产品接棒。

核心洞察：AI 公司估值逼近万亿但均未盈利（OpenAI 预计2026亏140亿）。收入验证了需求存在，但成本结构仍需算力降价才能扭亏。多云分发成为默认（OpenAI on Bedrock），模型不再是壁垒，平台生态和合规才是。
